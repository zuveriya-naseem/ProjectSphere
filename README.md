# 🎓 ProjectSphere

🔗 **Live Demo:** [https://projectsphere.vercel.app](https://project-sphere-kappa.vercel.app/)


A **React-based student group project management platform** designed to help teachers and students coordinate effectively through task tracking, progress visualization, and milestone submissions.

---

## 🚀 Features

### 👩‍🏫 Teacher / Admin
- Create and assign new group projects  
- Add due dates and task details  
- View each team’s progress  
- Add remarks and grades for submissions  
- Monitor all student uploads in one dashboard  

### 👩‍🎓 Student
- Login and access personal/team dashboard  
- View assigned work and deadlines  
- Upload completed tasks  
- Track project progress dynamically  
- See team members and their individual contributions  

---

## 🧠 Tech Stack

- **Frontend:** React.js  
- **UI Framework:** Material UI  
- **Animations:** Framer Motion  
- **State Management:** Context API  
- **Data Persistence:** LocalStorage  
- **Routing:** React Router  

---

## 🎨 UI Highlights

- Clean, modern interface with dark/light mode toggle 🌗  
- Responsive layout for all devices 📱💻  
- Smooth animated transitions for dashboards
